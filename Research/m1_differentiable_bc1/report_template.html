Mip / LOD：训练 mip vs 朴素导出 mip（M2）

每层 latent mip 为独立可训练的 BC1 参数，训练时连续采样 lod = Up·max_lod（默认 p=2，向低 LOD 加权），三线性 = 逐层解码 BC1 → 双线性 → 层间插值，与 GPU 行为逐位一致。朴素基线只训 base 层，mip 由“解码 → 2×2 box 下采样 → PCA 端点拟合重编码”生成（即传统导出器做法）。

mip 训练 朴素 mip 实线 = 4×512² · 虚线 = 4×256² · 点线 = 4×128²

朴素 mip 从 lod2 起崩到 26–31 dB——解码后的 BC1 内容经不起再量化；训练 mip 在 512 组以 lod0 −0.6 dB 的代价换来 lod1–4 全面 +4~5 dB。256 组（latent 比源粗一档）的 base 层被 lod0/lod1 两种目标共享，lod0 存在硬上限，--lod-pow 只在 lod0↔lod1 间做权衡（详见下表）。

PSNR（dB），逐 LOD 在对应参考 mip 分辨率的全网格上计算。结论：要 lod0 保真优先让 latent 分辨率等于源分辨率；latent 更粗时按资产调 p（training profile 参数，规格 §7.3）。

逐 mip 级 × 逐 latent 大小的重建对比：横向滑动切 LOD（0–4），纵向滑动切 latent 大小（4×512² / 4×256² / 4×128²）。每张卡片左上角为该配置含 mip 链显存相对直接 BC1 的百分比；卡内为全部 5 张输出贴图，行为 参考 / mip 训练 / 朴素 mip。图像统一 256px 展示（高 LOD 最近邻放大），全部由导出的 BC1 字节流经 numpy gold 路径重建。

从 lod2 起朴素 mip 的再量化噪点在所有通道上可见，lod3/lod4 偏色加剧；训练 mip 各级都贴近参考。latent 越小（显存百分比越低），base 层细节越少，但训练 mip 在高 LOD 的优势在每个大小档位上都成立。

位流与数据契约验证

  • 训练用模拟解码 与 打包位流的参考解码 逐纹素一致（最大误差 1.2e-7，bit 级路径）
  • 全部打包 block 满足 opaque 模式约束 c0 ≥ c1；端点交换时索引同步翻转（w→1−w）
  • 退化 block（端点相等）强制索引 0，杜绝 3-color/alpha 模式的透明黑
  • Pillow 独立 DXT1 解码器读取导出的 .dds，与我们的解码最大差 1 LSB（容差 2）
  • 5 组 M1 训练导出 × 10 项检查全部 PASS；fixtures.npz 可仅凭打包字节流复现训练时 MLP 输出（<1e-5）
  • M2：torch 三线性 与 numpy gold 三线性逐位一致（含 LOD 边界钳制）；DDS mip 链头部/逐级 payload 布局自测通过，Pillow 可读；全部 M2 导出的 (uv, lod) fixture 特征与 MLP 输出可由字节流独立复现

方法与训练记录

每个 4×4 block 的连续参数为两个端点 e0,e1∈[0,1]³ 与逐纹素权重 w∈[0,1]；前向按 STE 取整到 RGB565 / {0,⅓,⅔,1}，解码 texel = lerp(C0,C1,w)，与 BC1 opaque 四色调色板数学等价（规格 §5.3–5.4，方法参照 AMD NTBC 论文 §3）。

训练稳定性修复：初版直接 clamp(0,1) 导致越界参数梯度归零而永久“死亡”，扫描曲线非单调（512² 组仅 31.8 dB）。改为直通 clamp（梯度恒等）+ 每步后投影回 [0,1]（投影梯度下降），并将端点初始化拉开至 0.35/0.65 以避免 C1−C0≈0 时索引权重梯度消失。修复后同预算下 512² 组 31.8 → 39.0 dB，两条曲线均严格单调。
